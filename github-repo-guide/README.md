# GitHub 建網站教學（Chrome 擴充功能）

一步一步教你用 GitHub Pages 或 Render 發布網站（內容依照課堂簡報「Github Pages & Render 介紹」）。會自動提醒常見錯誤，也可以問問題。

面板上方可以選教學：

- GitHub Pages 方法 1：網頁上傳（推薦）
- GitHub Pages 方法 2：VS Code + Git
- Render：上傳後部署靜態網站
- 更新或刪除 repo 裡的檔案
- 直接在 GitHub 上寫 index.html
- 準備：安裝和設定 VS Code
- SEO（課堂簡報「連結 GA、GSC、GTM、sitemap」）：
  1. GA 申請與設定
  2. 在網站安裝 GA 追蹤碼
  3. GSC 新增網站並連結 GA
  4. 在網站安裝 GTM
  5. GTM 連接 GA（網頁瀏覽、捲動事件）
  6. 建立並提交 Sitemap
  7. 要求 Google 建立索引
  8. 新增 GA、GSC、GTM 管理員

面板會出現在 GitHub、Render、GA、GSC、GTM、xml-sitemaps.com，以及你自己的網站（`*.github.io`、`*.onrender.com`）。在 VS Code 裡做的步驟只有文字說明，不會有標示。

在你自己的網站上，面板會顯示「🔍 網站檢查」：檢查這一頁有沒有 GA 追蹤碼、GTM 的兩段程式碼（以及 ID 對不對），還有 sitemap.xml 和 robots.txt。

## 安裝

1. Chrome 網址列輸入 `chrome://extensions`，打開右上角「開發人員模式」
2. 按「載入未封裝項目」，選這個資料夾（`github-repo-guide`）
3. 打開 GitHub 並登入，右下角會出現教學面板

改過檔案後：在 `chrome://extensions` 按這個擴充功能的「重新載入 🔄」，再重新整理 GitHub 頁面。

## 問問題怎麼運作

1. 先用關鍵字比對 `faq.js` 裡的常見問題，有符合就直接回答（不用網路、不用安裝其他東西）
2. 找不到，或按「不是我要的答案，問 AI」，就交給**你電腦上的 Ollama** 回答（不會連到網路上的 AI）

## 設定 Ollama（想用 AI 回答才需要）

1. 到 https://ollama.com 下載並安裝 Ollama
2. 在 cmd 下載模型（約 2 GB，中文不錯）：

   ```
   ollama pull qwen2.5:3b
   ```

3. 允許擴充功能連線，在 cmd 執行：

   ```
   setx OLLAMA_ORIGINS "chrome-extension://*"
   ```

   然後從工作列右下角結束 Ollama，再重新開啟。

## 用截圖做新教學

不用改程式，也能做新的教學：

1. 面板最下面按「📷 用截圖做新教學」，會打開新分頁
2. 填教學名稱（和選填的「這套教學要做什麼」），把操作截圖拖進去、選檔案，或按 Ctrl+V 貼上
3. 按「🤖 產生步驟」，**你電腦上的 Ollama 看圖模型**會一張一張看，寫出標題、說明、要框的按鈕（有看到網址列也會填網址）
4. 檢查並修改每一步，按「儲存教學」。面板下拉選單的「我的教學（用截圖產生）」就會出現
5. 在網站上一樣會用橘色框標出按鈕；點了最後一個按鈕會自動跳下一步

- 需要看圖模型：`ollama pull qwen2.5vl:3b`。3B 小模型可能看錯，存之前請一定要檢查
- 截圖只用來產生步驟，不會存起來，也不會傳到網路上
- 做好的教學可以「匯出」成 JSON 傳給同學，同學按「匯入」貼上就能用
- 面板只會出現在 `manifest.json` 列出的網站（GitHub、Render、GA、GSC、GTM 等），其他網站的教學要先在那裡加網址

## 網站改版、找不到按鈕時：AI 看畫面

某一步的按鈕 4 秒內找不到，擴充功能會：

1. 收集畫面上所有可以點、可以填的元素，編號
2. 截圖，在每個元素上畫粉紅色框和編號（要先開截圖權限）
3. 交給**你電腦上的 Ollama 看圖模型**，請它選出這一步的按鈕
4. 用**紫色虛線框**標出 AI 推測的按鈕（正式的線索是橘色框）。點了它一樣會自動跳下一步
5. 記下來：同一頁不會再問一次；設定頁可以看到「改版紀錄」，確認後可以寫進 `courses.js`

設定方式：

- 看圖模型：`ollama pull qwen2.5vl:3b`（約 3 GB；有其他看圖模型也會自動用）
- 截圖權限：在 `chrome://extensions` 點這個擴充功能的「詳細資料」→「擴充功能選項」→「允許截圖」。
  Chrome 規定截圖要有「讀取所有網站」的權限，所以會跳出警告
- 沒開截圖權限或沒有看圖模型：改成只把按鈕清單交給文字模型判斷
- 面板上可以關掉「找不到按鈕時請 AI 看畫面」

想換模型，改 `background.js` 最上面的 `MODEL`（文字）和 `VISION_MODEL`（看圖）。電腦比較慢可以用 `qwen2.5:1.5b`，比較快但回答品質較差。
