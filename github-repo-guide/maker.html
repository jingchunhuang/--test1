📷 用截圖做教學

把操作畫面的截圖（例如課堂簡報的截圖）上傳到這裡，你電腦上的 Ollama 看圖模型會一張一張看， 自動寫出步驟標題、說明和要按的按鈕。改好之後存起來，教學面板的下拉選單就會出現這套教學， 在網站上一樣會把按鈕框起來。截圖不會傳到網路上。

需要先安裝看圖模型：在 cmd 執行 ollama pull qwen2.5vl:3b（約 3 GB），並照 README 設定 OLLAMA_ORIGINS。 一張截圖大約要等幾秒到一分鐘。

1. 教學名稱和截圖

把截圖拖曳到這裡，或點這裡選檔案，也可以直接按 Ctrl+V 貼上
可以一次選好幾張，會照檔名排序；之後可以用 ← → 調整順序

2. 檢查並修改步驟

AI 可能看錯，請確認每一步。「要框的按鈕」一行寫一個，要和網頁上按鈕的文字一樣（開頭一樣就可以）； 「網址」有填的話，不在那個網站時面板會提醒，並提供「帶我過去」。
