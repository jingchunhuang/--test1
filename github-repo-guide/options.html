模型：（空白就用 gemini-3.5-flash-lite）

⚠️ 用 Gemini 時，問題和網頁截圖會傳到 Google。免費方案的內容可能被 Google 拿去改進產品， 截圖裡可能有你的帳號名稱、repo 名稱，介意的話請用 Ollama。

AI 看畫面找按鈕

網站改版、找不到教學要按的按鈕時，擴充功能會把畫面截圖，在每個可以點的地方標上編號， 交給上面選的 AI 選出最可能的按鈕。用 Ollama 時截圖不會傳到網路上。

截圖權限：檢查中…

Chrome 規定擴充功能要截圖，必須有「讀取所有網站」的權限，所以按下「允許截圖」時 Chrome 會跳出警告。 擴充功能只會在找不到按鈕時截目前這個分頁。

用 Ollama 時要裝看圖模型：在 cmd 執行 ollama pull qwen2.5vl:3b（約 3 GB）。 沒有截圖權限（或 Ollama 沒有看圖模型）時，會改成只把按鈕清單交給 AI 判斷。

AI 找到的按鈕（改版紀錄）

這些是原本的線索找不到、由 AI 推測出來的按鈕。確認正確後，可以把它們寫進 courses.js 變成正式的線索。
