GitHub 建網站教學：設定

AI 看畫面找按鈕

網站改版、找不到教學要按的按鈕時，擴充功能會把畫面截圖，在每個可以點的地方標上編號， 交給你電腦上的 Ollama 看圖模型選出最可能的按鈕。截圖不會傳到網路上。

截圖權限：檢查中…

Chrome 規定擴充功能要截圖，必須有「讀取所有網站」的權限，所以按下「允許截圖」時 Chrome 會跳出警告。 擴充功能只會在找不到按鈕時截目前這個分頁。

看圖模型：在 cmd 執行 ollama pull qwen2.5vl:3b（約 3 GB）。 沒有截圖權限或沒有看圖模型時，會改成只把按鈕清單交給文字模型判斷。
